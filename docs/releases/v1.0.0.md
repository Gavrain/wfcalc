# v1.0.0（2026-11-16）

> 标签：`v1.0.0`　GitHub Release：https://github.com/Gavrain/wfcalc/releases/tag/v1.0.0

## 范围

**只修算错的口径，不加新口径。**

## 改了什么

- 乘区下限归零；弱点暴击率与普通暴率同乘区；重击 ×2 体现在面板上
- DoT 基础值收敛成一个；多重只影响叠层、不影响触发率本身
- 弹药效率上限 0.75；稳态秒伤按逐秒层数池并计入爆炸主目标；逐段面板
- 界面：稳态卡面增幅对齐 N 秒总伤；范围伤害栏修复

详见 [R-001](../requirements/R-001-核心口径修正.md)。
