# v1.3.0

发布日期：2026-11-18
上一版本：[v1.2.0](v1.2.0.md)

---

## 一句话

**增幅的全部规则移进内核**，内核不再有"界面才能算出来的东西"；顺带补齐近战的重击与震地口径。

**步枪与远程武器的数字不变**（冒烟 535.280 与 v1.2.0 一致）。**近战的重击震地数字会变大**，见第 4 节。

---

## 主要内容

### 1. 增幅规则移入内核

以前"这张卡值多少"的算法（取哪一行、分母怎么拼、DoT 怎么加权）全在界面层
`app-compute.js`。现在移进内核，分三个文件：

| 文件 | 内容 |
|---|---|
| `core/src/gain.ts` | 比值增幅、去掉来源的贡献 |
| `core/src/gain-rules.ts` | DoT 加权（`dotFactorOfCard`）、N 秒总量分母（`windowDenominator`） |
| `core/src/dot-role.ts` | DoT 口径下的增幅角色判定（照常 / 0 / 拆分） |

**分工**：内核提供**规则**；"跑一次计算、取某个口径"由调用方以**回调**传入——
内核不认识武器对象，也不碰界面状态。

界面上那批"去掉重算"的函数（`marginalGainOf` / `rivenGain` / 裂罅词条 / 候选）
统一走 `withSourceRemoved`。

### 2. 取数走索引

`contributionsFor` 内建属性索引（`WeakMap` 挂在贡献数组上）：
以前每取一个属性就扫一遍全表，现在建一次索引后 O(1)。

**元素合成的顺序被特意保住**——索引按原顺序存，合成结果不变。

### 3. 素材池补 `scope` 语义

素材池新增 9 项对照测试，逐个属性证明它和计算路径（`sumPct` / `sumFlat` / `productMul`）
算出的完全一致，包括 `active: false` 与 `scope: 'hit' | 'dot'` 两种情况。

### 4. 近战：震地口径 + 刃影 + 连击

**⚠️ 这一节的数字与 v1.2.0 不同。**

#### 震地口径

震地（含重击震地）**不产生弹丸、没有攻速概念**，所以：

- **不展示**爆发 / 续航 / N 秒这些按时间摊的口径；
- 只展示「单次攻击」（就是单次震地伤害）与「震地 DoT 潜力」。

> 震地 DoT 潜力恒为 **0**：震地的伤害类型是冲击与爆炸，两者都没有 DoT。如实反映。

#### 近战口径改称

| 远程 | 近战 |
|---|---|
| 单弹头 `/弹头` | **单击** `/击` |
| 单次射击 `/发` | **单次攻击** `/次` |
| 连发秒伤 | **每秒伤害** |

数值不变，只换显示名。

#### 刃影 = 实弹多重

刃影（近战·刃影）在数值上当"实弹多重"用：

```
攻击次数 = 1 + w × P1(cc)
```

| 暴击率 | 0% | 50% | **100%** | 150% | **200%+** |
|---|---|---|---|---|---|
| 刃影多重（满级） | 1.0 | 1.5 | **2.0** | 1.5 | **1.0** |

与真正的多重唯一的差别是系数来源：多重来自 Mod 的固定百分比，刃影来自一级暴击概率。

#### 连击倍率只乘重击

近战的连击倍率（那个 ×N）**只乘重击伤害**：12x 连击时，重击震地打 12 倍伤害。

**乘在基伤源头、只乘一次**——命中与 DoT 基础值都从它派生，自动带上。

连击对 Mod 层数的影响（急进猛突那类）是另一回事，在数据层换算，两者都算。

**实测（某些近战 + 毒卡）**：

| | 连击 1x | 连击 12x |
|---|---|---|
| 重击 单次攻击 | 1116.06 | **13392.69** |
| 重击 DoT/层/秒 | 558.03 | **6696.35** |
| 普攻 单次攻击 | 372.02 | 372.02（不变） |

## 已知限制

1. **重击蓄力时间没做**（需求方 2026-11-18：「蓄力先不做了」）。数据里有 `heavyWindup` 卡，内核没读。
2. **普通重击没有独立模式**：数据里 `_heavy` 标记只落在"重型震地攻击"上。
3. 素材池的多场景并排显示没做（需求方：「先不搞吧」）。
