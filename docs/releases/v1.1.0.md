## ⚠️ 会改变数字的改动（验收重点）

### 1. DoT：每秒都跳，每层独立到期（R-008）

**旧行为（错的）**：毒 / 电 / 切割被当成"每层只跳一拍"，等于每层只结算一次；层数只增不减，装填期间直接归零。

**新行为**：所有 DoT 每秒都跳一次，每层独立计时、活满持续时间才掉。

| 场景（每秒 2 层、每跳 100） | v1.0 | v1.1 |
|---|---|---|
| 毒 / 切割 6 秒合计 | **800** | **4200** |
| 火 6 秒合计 | 2400 | 4200 |

**毒、电、切割的伤害会大幅上涨**，这是修正，不是回归。

### 2. 异常状态持续时间接上了（R-008）

以前 7 张状态持续卡（未完之刺 / 预言 探求 / 永恒苦痛 / 毒素数列 / 猎人 追踪 / 无尽苦难 / 恒久折磨）**完全无效**。

现在：持续时间 = `6 × (1 + Σ异常状态持续%)`，**每跳伤害不变，只拉长存活时间**。

> 注意：当前窗口是 1~6 秒，**6 秒窗口内看不出状态持续的收益**（层还没到期）。
> 20 秒窗口实测：毒 持续 6 秒 = 23800，持续 12 秒 = 36400。

### 3. 连击倍率换算修正（R-007）

**旧**：`每层值 × 连击倍率`（12x 时急进猛突 = +480%）
**新**：`每层值 × (连击倍率 − 1)`（1x 不加，2x 起算；12x 时 = **+440%**）

**近战暴击率会降低**。受影响：急进猛突、创口溃烂、角斗士套装。

### 4. 套装效果从"完全没实现"到"生效"（R-007）

此前计算链里**一个套装效果都没读**。现在：

| 套装 | 效果 | 武器上最多几张 |
|---|---|---|
| 牺牲 | 本套 Mod 数值 **×1.25 一次** | 2 |
| 私法 | 每件 **+5% 固定暴击率** | 4 |
| 混沌（尼拉） | 每件 **+150% 震地攻击伤害** | 1 |
| 角斗士 | 每件 **+10% ×（连击倍率−1）** | 3 |

诡文（Boreal）是空中减伤，不影响输出，不进表。

## 其他改动

### 数据层：换算搬进流水线（R-007）

- 写死的效果表（10 张）从 `adapter.ts` 搬进 `manual/mods.ts` / `manual/arcanes.ts`；
- **内核键 `contribStat` 在生成阶段算好**写进 `mods.json`，内核启动不再查表；
- 内核删掉运行时 `toContribStat` 兜底。

### 数据补全（R-009）

**补 25 张缺失的 Mod**（基线 543 → 568，生成 478 → 503）：

- **空战近战 19 张**（此前整类缺失，8 把空战近战武器装不了任何 Mod）；
- 常规：锁定目标（狙击 +60% 弱点伤害）、有去无回（手枪 +90% 穿刺）；
- 空战枪：带电枪管 Prime（+187% 电）；
- 限武器类别：诡文枭主之鄙（长柄）、混沌蛇主之鄙（鞭）、致命匿杀（匕首）。

**按武器类别限装**：新增 `COMPAT_CLASS_TO_SPECIFIC` 表 + 判定三段式（通用类别 → 武器类别比细类 → 具体武器名）。

**排除**：PvP 卡 162 张（`uniqueName` 含 `PvPMods` 或掉落自 Conclave）；雷火等"伤害转类型"类不做；雷筒 Prime / 蓄力装填 Prime 国际服暂无获取途径，不进数据。

### 裂罅换算搬进内核（R-010）

界面只传「词条键 + 幅度 + 正负」，换算在 `core/src/input/riven.ts`。
内核直接丢掉不影响伤害的词条（后坐力 / 缩放 / 穿透 / 弹速 / 状态持续 / 弹药上限）。

### 切割规则（R-010）

- 切割 DoT **不吃切割 Mod 的元素 %**（元素乘区恒为 1+0）；
- 切割卡在**单层口径**下增幅 0，在**总量口径**下照常算（占比变大 → 层数变多）。

### 增幅计算统一（R-010）

- 备选卡与已装卡共用 `gainOfPair`；
- 分母一律取**内核算好的那一行**（`totalInWindow` / `steadyDps`），不再自己拼 `续航 × N + dot6s`。

**顺带修正**：稳态口径下白霜弹头增幅原来显示 **+4.0%**，真值 **+50.8%**。

### 界面拆分（R-011）

`app.js` **3823 → 939 行**，拆出 10 个模块：

| 模块 | 行数 | 职责 |
|---|---|---|
| `ui-dom.js` | 39 | `$` / `el` / `fmtGain` / `flash` |
| `ui-parts.js` | 74 | 可复用小组件（折叠块 / DoT 行） |
| `ui-labels.js` | 109 | 卡面文字（无依赖） |
| `ui-chips.js` | 115 | 卡面小标签 |
| `ui-candidates.js` | 267 | 备选卡 + 筛选 |
| `ui-detail.js` | 322 | 拆解面板 |
| `ui-weapon.js` | 322 | 武器选单 / 搜索 / 切换 |
| `ui-slots.js` | 336 | 槽位 + 拖放 |
| `ui-controls.js` | 421 | 玄骸 / 镀层 / 模式 / 爆头 |
| `ui-panel.js` | 435 | 面板 + 输出 + 伤害分布表 |
| `ui-riven.js` | 491 | 裂罅编辑器 |

**所有模块都有注入自检**：少注入一项会打 `console.error`，不再静默失效。

### 其他修正

- **换武器时配置项归位**（R-012）：以前爆头 / 派系 / 玄骸 / 异况层数会沿用上一把武器的值；

## 已知问题

1. **6 秒窗口内看不出状态持续的收益**——层还没到期。要看收益需切换更长窗口（当前界面限制 1~6 秒）。
2. **尼拉 / 私法 / 角斗士的战甲卡不参与计算**，套装按"武器上最多几张"截断，与游戏内实际（可带战甲卡）不同。
3. **`app.js` 仍有 939 行**（启动 / 调度 / 存档 / 槽位操作），属外壳职责，暂不继续拆。
4. **增幅的「已装卡」与「备选卡」已统一**，但裂罅词条增幅仍走单独路径（数值已验证一致）。
