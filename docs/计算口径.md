## 0. 一句话总览

```
最终伤害 = 面板 → 玄骸 → 基伤 → 元素加量/合成 → 暴击与爆头 → 触发与 DoT → 派系
```

**只算到「命中伤害」层**：目标结算（护盾/护甲/生命）暂缓（C-13）。
**不做战甲模型**：武器之外的加成一律走「自定义加成」入口。

## 1. 通用乘区骨架

任何可被 Mod 加成的属性都走这一个式子（`乘区归属表.md` 2.0）：

```
值 = ( 面板 × (1 + Σ pct) + Σ flat ) × Π mul
```

- 三种输入形态：`pct` 百分比加算 / `flat` 绝对值加算 / `mul` 独立乘算（三选一）
- 同一属性在同一乘区内相加，**乘区之间相乘**——这是「每个乘区可拆解」的基础
- 冻结加算项目前只有暴率、暴伤各一个（私法套装入暴率）

## 2. 各乘区一句话结论

| 乘区 | 结论 | 出处 |
|---|---|---|
| **基伤** | 双基本值；灵化基伤不吃镀层类、不吃 AoE | C-01 |
| **多重** | 只体现在一个括号里；**`当前多重 = 面板多重 × (1+Σ%) + Σ绝对值`**，面板多重取 `modes[].multishot`（57 把武器自带多重，**不是常量 1**），`bullets` 只做溯源 | C-01 / C-12 / D-076 |
| **暴击** | 平均伤害用总爆伤；上下限才用分档实际倍率 | C-03 |
| **爆头** | 开关，独立乘区；`爆头且暴击 = 爆头倍率 × 暴击倍率 × 2`，×2 只作用于暴击 | C-15 |
| **元素 / 物理** | 不是总伤害放大器：**按类型各自算加量**，物理不跟着放大元素 %；基数 = 玄骸加成后的新面板 | C-04 / C-20 |
| **元素合成** | 同类型**先加总**再两两配对；自带元素排槽位 9~12（Mod 之后） | C-10 / C-19 |
| **玄骸** | **在基伤之前**并入面板，吃基伤加成 | C-16 |
| **镀层类** | `x% × a × y`（a = 目标异常状态种类数，y = 叠层上限） | C-18 |
| **射速** | `(面板 × (1+Σ%) + flat) × Πmul` | C-02 |
| **派系** | 最终独立乘区，同派系相加、异派系只一个生效；DoT 上生效**两次** | C-06 / C-05 |
| **DoT** | 基础值 = 剔除元素/物理 Mod 加量的命中伤（含暴击、爆头）；每层秒伤 = 单层，六秒总伤才乘层数 | C-05 / C-11 / C-21 / C-22 |
| **爆炸** | 独立异常状态：1.5s 延迟、10 层满层系数 0.3 → 3、满层才产生范围伤害，**单列** | C-17 |
| **目标结算** | **暂缓**（护盾/护甲/生命第 7 节保留为规格） | C-13 |

## 3. 输出口径（5 个）

| 口径 | 实弹类 | 射线类 |
|---|---|---|
| 单弹头伤害 | 基础伤害项（**不含**多重括号） | 基础伤害项 × 当前多重，与单次射击相同 |
| 单次射击伤害 | 单弹头 × **当前多重**（含面板多重） | 同单弹头 |
| 每秒命中伤害 | 单次射击 × 射速最终值，**不含装填** | 同左 |
| 每秒 DoT 伤害 | 6 秒逐秒曲线 | 同左 |
| 持续射击 DPS | 单次射击 × 弹匣 ÷ (弹匣/射速 + 装填) | 同左 |

- 全程**不用除法**求单弹头（不是"总伤 ÷ 弹头数"），各口径都从同一个基础伤害项派生
- 装填窗口用**毫秒精度开火占比**；装填期间不叠新层，已有层照常跳（C-24）

## 4. 最容易写错的三条

| # | 口径 | 错误写法 | 正确写法 |
|---|---|---|---|
| 1 | DoT 基础值 | 直接用单弹头伤害 | **剔除元素/物理 Mod 加量**后的命中伤（保留基伤 %、多重 %、暴击） |
| 2 | 元素 % Mod | 当成总伤害放大器 | 只是**按新面板总伤算出该元素自己的加量**，物理**不**跟着放大 |
| 3 | 暴击 | 平均伤害和上下限用同一个式子 | 平均用总爆伤；上下限才用分档实际倍率 |
