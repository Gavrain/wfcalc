## 0. 输出口径定义

> 全文最优先的口径约定。后续各节的所有公式都必须能落到这几个口径上。
> **全程不使用除法**，各口径从同一"基础伤害项"派生。

### 0.1 伤害口径

```
射速最终值 = ( 面板射速 × (1 + Σ射速Mod%) + 固定加算值 ) × 射速额外乘区
```

| 口径 | 实弹类 | 射线类 |
|---|---|---|
| 单弹头伤害 | 基础伤害项（**不含**多重括号） | 基础伤害项 × (1+Σ多重Mod%)，与单次射击相同 |
| 单次射击伤害 | 单弹头伤害 × (1+Σ多重Mod%)（一次射击所有弹头） | 同单弹头伤害 |
| 每秒命中伤害（DPS） | 单次射击伤害 × 射速最终值，**不含装填** | 同左 |
| 每秒 DoT 伤害 | **6 秒变化曲线**（见 0.2） | 同左 |
| 持续射击 DPS | 单次射击伤害 × 弹匣数 / (弹匣数 / 射速最终值 + 装填时间) | 同左 |

- 实弹「单弹头伤害」**不是**总伤害除以弹头数，而是直接从基础伤害项出发、不加多重括号。
- 持续 DPS 采用**平滑折算口径（B）**：单次射击 × 弹匣数 ÷ (弹匣数/射速 + 装填)。

### 0.2 DoT 的 6 秒变化曲线（替代"稳态/首发"单值）

DoT 输出改用**0~6 秒逐秒曲线**展示，比单一稳态值信息更完整。

```
前提：持续射击中，从 t=0 开始计时
      按射速与触发期望逐秒叠层，曲线反映"叠层过程"
横轴：固定 0~6 秒（与火焰/毒素/毒气的 6 秒持续时长一致）
```

| DoT | 曲线形状 | 原因 |
|---|---|---|
| **火焰** | **单调上升**（伤害持续增加） | 每次触发为触发器**累加基础值**，层数越多每跳越高 |
| 毒素 / 电击 / 切割 / 毒气 | 按各自叠层规则累加（毒气 10 层封顶后转平） | 层数增长后趋于稳定 |
| **爆炸** | **按每秒平均伤害**给出 | 非 DoT，按结算事件摊到每秒 |

**爆炸的两种结算必须区分**：

```
满 10 层 → 立即结算：造成 10 次 30% 单体 + 范围 300%/层（10 倍）
未满 10 层 → 满时长结算：只有单体伤害，【没有范围伤害】
```

- 曲线里爆炸取**每秒平均**：先按期望每秒加层判断 1.5 秒内能否满 10 层，
  能则按「立即结算（含范围 10 倍）」计，否则按「满时长结算（无范围）」计。

### 0.3 触发的"概率-层数"口径

触发率允许 > 100%，按**「整数层数 + 小数部分概率」**解释：
`250%` = 必定触发 2 层，另有 50% 概率触发第 3 层。期望层数直接取触发率本身（2.5）。

```
① 单弹头总触发率（全体元素合计）
   = 面板 procChance × (1 + Σ触发率Mod%)
     （射线：再 × (1 + Σ射线多重%)）

② 单弹头某个元素的触发概率（占比 / 权益）
   = 该元素伤害 ÷ 「所有类型伤害」之和

③ 单弹头某个元素的期望层数
   = ① 单弹头总触发率 × ② 该元素占比

④ 单次射击某个元素的期望层数
   = ③ × 多重
     （射线武器不再额外 ×多重：射线的多重已并入 ① 的触发率，此处 ③ 已含）
```

- ② 输出的「概率」是**该元素在触发池里的份额**，不是该元素单独出现的绝对概率；
  绝对概率 = ① × ②。
- ① 是所有元素合计的结果，**不能直接当某一种元素的触发率用**，必须再乘 ② 的占比拆开。
- 射线武器已在 ① 的触发率公式里乘过 `(1+Σ射线多重%)`，④ **不重复乘**。
- 伤害性异常状态（DoT）的基础值口径见第 6.2 节：
  **剔除元素/物理 Mod 加量后的命中伤（含暴击、含多重）**，
  **不是**含 Mod 加量的单弹头伤害。
  → 射线与实弹的差别仍体现在这个基础值里：射线多重已并入命中伤。

## 1. 结算链总览

> 通用乘区骨架：**任意属性 = ( 面板值 × (1 + ΣMod%) + 固定加算值 ) × 额外乘区**。
> 固定加算值目前只在暴击率、暴击伤害两处各设一个；额外乘区按需独立叠加。

```
面板基础值
  → L1 加法乘区（基伤、多重、暴率、暴伤、触发、元素、射速…）   ← 每个乘区各自走上面的骨架
        · 基伤：面板基伤×(1+基伤Mod%+镀层%) + 灵化基伤×(1+基伤Mod%)
        · 多重：独立乘区 ×(1+Σ多重Mod%)；射线合并为一跳
  → L2 元素加量（按类型算加量：元素%基数为新面板总伤；再按槽位两两合成复合元素）
  → L3 暴击结算（平均伤害用总爆伤；上下限用分档实际倍率；爆头）  ← 只算期望与最大最小，不做分布
  → L4 触发状态机（触发率→元素占比→期望层数；DoT 基础值剔除元素/物理 Mod 加量）
  → L5 目标结算（超宏 → 护盾 → 护甲/削甲 → 生命）与派系乘区
  → 输出口径（见第 0 节）：单弹头 / 单次射击 / 每秒命中 / 每秒 DoT / 持续射击 DPS
```

## 2. 基伤与多重

> 本节已于 2026-11-04 与需求方逐条确认，口径固化为下方公式。

### 2.0 通用乘区骨架（所有属性共用）

```
任意属性 = ( 面板值 × (1 + ΣMod%) + 固定加算值 ) × 额外乘区
```

- **固定加算值**：加法项，目前只在**暴击率**、**暴击伤害**两处各设一个。
- **额外乘区**：乘法项，必要时独立叠加（如射速的「射速额外乘区」）。

### 2.1 基伤（双基本值）

```
基础伤害项 = 面板基伤 × (1 + Σ基伤Mod% + 镀层%类)      // 镀层类 = 「每个异常状态 +X% 伤害」词条，如镀层准确射手
           + 灵化基伤 × (1 + Σ基伤Mod%)                 // 灵化词条基伤是"裸的"
```

- 基伤 = 所有「+X% 伤害」词条，来源包括 **8 个 Mod 槽位 + Riven + 赋能**，**不限槽位、全部相加**。
- 「异常状态 +X% 伤害」类词条**不对灵化词条基伤生效**，也**不对范围伤害（AoE）生效**。
  → 灵化基伤项只吃 `(1 + Σ基伤Mod%)`；AoE 段同样只吃 `(1 + Σ基伤Mod%)`，不吃镀层类。

### 2.2 多重（独立乘区）

```
总伤害 = 基础伤害项 × (1 + Σ多重Mod%)
```

- 基伤与多重是**两个独立乘区，相乘**，绝不相加。
- 自带多重的武器（霰弹枪、幻离子等）：**面板多重就是基础值**，Mod 是在此基础上按百分比加多重数值。
- **实弹类**：多重**只**体现在 `(1 + Σ多重Mod%)` 这一个括号里，无其他隐藏项；弹头数用于把「单弹头伤害」折算为「单次射击伤害」，不涉及除法。
- **射线类**（含幻离子等自带多重的射线）：多条激光击中同一敌人时**合并成一跳**；多重增加激光条数，但表现为一跳更高的伤害。因此伤害口径上射线=「弹头数恒为 1，多重并进伤害」。

### 2.3 射线武器的触发率

```
非射线：触发率 = 面板 procChance × (1 + Σ触发率Mod%)
射线：  触发率 = 面板 procChance × (1 + Σ触发率Mod%) × (1 + Σ射线多重%)
```

- 多重**不再**按弹头分摊触发率（"按弹头分摊"是过期攻略，已废弃）。

### 2.4 期望口径

- 多重小数部分、暴击：**只计算期望平均伤害与最大/最小伤害，不做随机模拟、不探究分布**。

| 属性 | 乘区 | 与其他属性的关系 | 状态 | 备注 |
|---|---|---|---|---|
| 基伤 +X% | baseDamage | 面板基伤×(1+Σ基伤Mod%+镀层%) + 灵化基伤×(1+Σ基伤Mod%) | ✅ | 不限槽位；镀层类不吃灵化基伤与 AoE |
| 多重 +X% | multishot | 独立乘区，`×(1+Σ多重Mod%)` | ✅ | 面板多重为基础值；实弹无隐藏项 |
| 基伤与多重是否同乘区 | — | **两个独立乘区相乘** | ✅ | 最易算错的一条 |
| 多重对触发的影响 | — | 实弹：每弹头独立判定、**不分摊**；射线：触发率额外 ×(1+Σ射线多重%) | ✅ | 按弹头分摊已废弃 |
| 多重的小数部分 | — | 以期望值参与计算，不做随机模拟 | ✅ | 可复算优先 |
| 单弹头各元素触发概率 | — | 该元素伤害 ÷ 所有类型伤害之和（触发池占比） | ✅ | 绝对概率 = 总触发率 × 占比 |
| 单次射击期望层数 | — | 总触发率 × 元素占比 × 多重（射线不重复乘多重） | ✅ | 触发率可 >100%，取整数层 + 小数概率 |
| DoT 伤害基础值 | — | **剔除元素/物理 Mod 加量**后的命中伤（保留基伤%、多重%、暴击） | ✅ | 见第 6.2 节 |

## 3. 暴击

> 暴击率与暴击伤害都遵循第 2.0 节通用骨架：`(面板值 × (1+ΣMod%) + 固定加算值) × 额外乘区`。

### 3.1 暴击等级与倍率

> **两个不同的量，分两条线用，不要混进同一个式子：**
> - **平均伤害**：连续加权，用的是**总爆伤**；
> - **上下限**：分档取值，用的是**各等级的实际倍率**。

```
平均伤害     = [ 暴率 × (总爆伤 - 1) + 1 ] × 伤害          ← -1 项永远是总爆伤

等级 k       = floor(暴率 / 100%) 起，相邻两级分别算：
实际暴击倍率 = 1 + k × (总爆伤 - 1)                          ← 仅用于上下限
```

- `总爆伤` = 第 2.0 节骨架算出的暴伤值。
- **暴击等级（A 口径）**：`k_min = floor(暴率 / 100%)`，小数部分 `frac(暴率)` 为升一级的概率。
  例：暴率 150% → 必中 1 级 + 50% 概率 2 级。
- **平均伤害**：`[暴率 × (总爆伤 - 1) + 1]`，**不出现「实际倍率」**。
  校验：暴率 150%、总爆伤 2.0 → [1.5 × (2-1) + 1] = **2.5×**，
  与「50% 打出 2.0× + 50% 打出 3.0×」的期望一致。
- **上下限伤害（带概率加权展示）**：取**相邻两个暴击等级**，各自按
  `1 + k × (总爆伤 - 1)` 算出 `实际暴击倍率`，并标注该档概率
  （下档 `1 - frac`、上档 `frac`）。
  展示如「等级 1（50%，2.0×） / 等级 2（50%，3.0×）」。
  不做随机模拟、不探究分布。

### 3.2 爆头（弱点）结算

- 大多数人形敌人**头部**被命中时受到额外伤害；**默认爆头倍率 3.0×**，
  但**不同敌人有不同爆头倍率**，需在目标模型里按敌人配置（见第 7 节 `headshotMultiplier`）。
- **爆头倍率与 Mod 加成按百分比增加叠加**：`最终爆头倍率 = 基础爆头倍率 × (1 + Σ爆头Mod%)`。
- **爆头时若产生暴击，最终伤害直接 ×2**（等效于总爆伤翻倍，再按 3.1 公式算）。
- **适用范围**：爆头加成对 DoT **适用**；**射线合并跳**按合并后的整体命中头部结算。

| 属性 | 乘区 | 与其他属性的关系 | 状态 | 备注 |
|---|---|---|---|---|
| 暴击几率 +X% | critChance | (面板暴率×(1+Σ暴率Mod%) + 固定加算值) × 额外乘区 | ✅ | 固定加算值目前已在暴率区设一个 |
| 暴击伤害 +X% | critMultiplier | (面板暴伤×(1+Σ暴伤Mod%) + 固定加算值) × 额外乘区 | ✅ | 同上，固定加算值各一个 |
| 暴击等级 | — | `k_min = floor(暴率/100%)`，`frac(暴率)` 为升级概率 | ✅ | A 口径 |
| 实际暴击倍率 | — | `1 + k × (总爆伤 - 1)`，k 为等级 | ✅ | **仅用于上下限**，不用于平均伤害 |
| 平均伤害 | — | `[暴率 × (总爆伤 - 1) + 1] × 伤害`（**不含实际倍率**） | ✅ | 校验：暴率150%/爆伤2.0 → 2.5 |
| 上下限伤害 | — | 相邻两个等级各自算 `1 + k × (总爆伤 - 1)`，并标注各档概率 | ✅ | 如「等级1（50%，2.0×）/ 等级2（50%，3.0×）」 |
| 爆头倍率 | — | 默认 3.0×，按敌人配置 `headshotMultiplier` | ✅ | 目标侧，见第 7 节 |
| 爆头 × Mod | — | `基础爆头倍率 × (1 + Σ爆头Mod%)`，百分比增加 | ✅ | |
| 爆头 × 暴击 | — | 爆头且暴击 → **最终伤害 ×2** | ✅ | 等效总爆伤翻倍 |
| 爆头对 DoT | — | **适用** | ✅ | |
| 爆头对射线合并跳 | — | **按合并跳整体结算** | ✅ | |
| 暴击期望口径 | — | 只算期望平均伤害与最大/最小伤害，不做随机模拟、不探究分布 | ✅ | 与第 2.4 节一致 |

## 4. 元素

> **建模前提（2026-11-05 确认）**：元素加成**不是"先加总再乘一个公共括号"**，
> 而是**对每一种伤害类型各自维护一个变量，最后汇总**。这是解决「玄骸加成与已有元素冲突」的唯一自洽方式。

### 4.1 伤害类型向量模型（加法量，不是放大器）

每种伤害类型 `t`（冲击/贯穿/切割/火/冰/电/毒/复合…）各自维护一个变量，
加成**以各自对应的基数算出「加量」**，加完后按类型汇总：

```
面板向量     = { t: 面板伤害_t }                       // 物理 3 种 + 元素若干
面板总伤     = Σ_t 面板伤害_t

① 玄骸加成（独立乘区，作用于面板，形成「新面板」）
   新面板总伤 = 面板总伤 × (1 + 玄骸比例)                 // 25%~60%

② 元素 %Mod（基数 = 新面板总伤）
   元素 %Mod 先加总；各元素加量按该元素归属，加到对应类型上
   元素类型 t：加量_t = 新面板总伤 × Σ该元素Mod%
   → 加量是「按加成比例放大该元素对应的伤害」，物理类型不参与放大

③ 物理 %Mod
   物理类型 t：加量_t = 面板伤害_t × Σ该物理类型Mod%

单类型最终_t = 面板伤害_t + 加量_t（+ 玄骸/额外加成）
总伤害       = Σ_t 单类型最终_t
```

**要点：元素% 并不是伤害放大器。** 它只是以「新面板总伤」为基数，算出**该元素类型自己的加量**；
物理类型**不会**跟着一起被放大。多个元素 %Mod 之间**先加总**，再按元素归属加量。

> **校验例 1**：面板 100 冲 + 100 切，上 100% 冲击 + 100% 毒素
> → 冲击加量 = 100×100% = 100，毒素加量 = 200×100% = 200
> → 结果 **200 冲 + 100 切 + 200 毒** ✅

### 4.2 物理与元素的关系

| 项目 | 结论 |
|---|---|
| 物理伤害 +X%（贯穿/冲击/切割） | 加量基数 = **该物理类型自身的面板值** |
| 元素伤害 +X% | 加量基数 = **新面板总伤**（含玄骸加成）；多个元素%先加总 |
| 玄骸加成 | **独立乘区**，新面板 = 面板总伤 × (1+比例) |
| 是否同一个括号 | **不是**：按类型分别算加量，最后汇总 |
| 物理是否被元素%放大 | **否**，物理保持原样 |

### 4.3 元素组合顺序（两两合并）

- **按 Mod 槽位顺序，从前往后（从小到大）两两合并**；后放的元素与已存在的单元素配对。
- **复合元素一旦合成即视为整体**，不能再被拆开或作为基础元素参与新组合。
- **Riven 词条**：若同时出现两个元素，**由下至上**计入排列顺序。
- **自带"额外基础元素"的武器**（赤毒 / 信条 / 终幕）：
  - 若武器自带元素伤害（如信条斯派克斯自带火），额外元素的**组合顺序优先级**为：
    **火焰 > 冰冻 > 电击 > 毒素**；
  - 这些额外元素**视为位于 Mod 槽位 9、10、11、12 号**，
    按照「槽位从小到大两两组合」的同一套逻辑参与合成。

### 4.4 玄骸 / 赤毒类额外元素

```
玄骸加成量 = 面板总伤 × 加成比例        // 25%~60%，通常取 60%
            → 独立乘区，作用于面板伤害，形成「新面板」
加成类型 ∈ { 冰、火、毒、电、磁力、辐射、冲击 }
```

- **玄骸加成是独立乘区**，作用在面板伤害上，结果即「新面板」（新总伤 = 面板总伤 × (1+比例)）。
- **Mod（元素%Mod）与玄骸加成是两个东西**：元素 %Mod 的基数就是**新面板总伤**。
- **冲击类型**：与面板冲击**合并为同一类型**，并**享受物理% Mod 增幅**（与面板冲击同待遇）。
- **参与组合**：视为位于槽位 9~12，与已有元素按两两合并逻辑合成（见 4.3）。
- **玄骸加成自身不会被再乘一次**：数值保持 `面板总伤 × 比例` 不变，只是参与构成新面板基数。
- **若上的是对应元素的 %Mod**（如磁力%）：会额外附加一份该元素伤害，
  最终与已有同类型伤害**合并**（归类到同一类型变量）。

> **校验例 2**（来自需求方实例）：面板 10穿+10切+10冲+10火 = 40，60% 磁力加成
> → 磁力加量 = 40×60% = 24，新总伤 = 64
> → 再上 100% 毒素：毒素加量 = 64×100% = 64
> → 毒素 64 与面板火 10 复合，形成 **74 毒气**；磁力**保持 24 不变** ✅

### 4.5 已确认结论

- 元素% 是「按基数算加量」的加算项，**不是总伤放大器**。
- 基数 = 玄骸加成之后的**新面板总伤**，所以玄骸加成**参与了基数的构成**；
  但玄骸加成自身**不会被元素% 再乘一次**（数值固定为 `面板总伤 × 比例`）。

| 属性 | 乘区 | 与其他属性的关系 | 状态 | 备注 |
|---|---|---|---|---|
| 元素伤害 +X% | elemental | 加量 = **新面板总伤 × Σ该元素Mod%**（先加总），加到对应类型 | ✅ | 不是放大器；物理不放大 |
| 物理伤害 +X%（贯穿/冲击/切割） | physical | 加量 = **该物理类型面板值 × Σ物理Mod%** | ✅ | 与元素分开 |
| 物理与元素是否同乘区 | — | **否**，各自按类型算加量后汇总 | ✅ | 无"公共括号" |
| 元素组合顺序 | — | 槽位从小到大两两合并，后放覆盖前放 | ✅ | |
| Riven 双元素 | — | 由下至上计入顺序 | ✅ | |
| 复合元素能否再叠加 | — | **不能**，合成即整体 | ✅ | |
| 自带额外元素（赤毒/信条/终幕） | — | 优先级 火>冰>电>毒，视为槽位 9~12 | ✅ | |
| 玄骸加成 | — | **独立乘区**，新面板 = 面板总伤 × (1+比例)，25%~60% | ✅ | 玄骸加成不再被 Mod 二次放大 |

## 5. 派系

> **术语澄清（2026-11-05）**：**派系加成**只指「对 Corpus / Grineer 等**敌人归属阵营**的 +X%」。
> **削甲不是派系加成**（它减少护甲减伤）；**弱点也不是派系加成**（已第 3 节按爆头倍率结算）。

### 5.1 命中伤害的派系加成

```
最终伤害 = 总伤害 × (1 + Σ该目标派系Mod%)
```

- **作用位置**：作为**最终独立乘区**，在汇总总伤害之后乘一次。
- 对目标所属派系生效的那一组 Mod 才计入；**目标不匹配则该乘区 = ×1**。

### 5.2 多派系 Mod 的叠加

- **同一派系**的多条 Mod：**相加**后乘一次。
- **不同派系**的 Mod：同一时刻**只有一个生效**（即目标所属派系），
  其余表现为 `×1`，故选 A 的「同派系相加」。

### 5.3 DoT 的派系加成（两次）

DoT 的派系加成**客观发生两次**，这不是“平方”这种说法：

```
第一次：计算 DoT 基础命中伤时，命中伤害已享受一次派系加成（第 6.2 节 ①）
第二次：DoT 每跳时，再乘一次派系加成（第 6.2 节 ③）
```

### 5.4 常见混淆项（都不是派系加成）

| 项目 | 归属 | 说明 |
|---|---|---|
| 削甲加成 | **目标护甲结算** | 减少护甲减伤，见第 7 节 |
| 弱点 / 爆头倍率 | **第 3 节暴击** | 命中弱点享受弱点倍率，未命中不享受 |
| 对某派系 +X% | **本节** | 仅按敌人归属阵营判定 |

| 属性 | 乘区 | 与其他属性的关系 | 状态 | 备注 |
|---|---|---|---|---|
| 对某派系 +X% | faction | 最终独立乘区：`总伤害 × (1+Σ该派系Mod%)` | ✅ | 目标不匹配则 ×1 |
| 多条对派系 Mod | — | **同派系相加**；不同派系同时只一个生效 | ✅ | |
| 派系对 DoT | — | **两次**：基础命中伤一次 + DoT 每跳一次 | ✅ | 非"平方" |
| 削甲 / 弱点 | — | **不属于派系加成** | ✅ | 分别在护甲结算与第 3 节 |

## 6. 触发与 DoT

> 本节分两部分：**触发判定**（已有结论）与 **DoT 结算**（2026-11-05 新增确认）。

### 6.1 触发判定

| 属性 | 乘区 | 与其他属性的关系 | 状态 | 备注 |
|---|---|---|---|---|
| 触发几率 +X% | statusChance | 非射线：面板 procChance × (1+Σ触发率Mod%)；射线：再 ×(1+Σ射线多重%) | ✅ | **不再按弹头分摊**（过期攻略） |
| 触发几率上限 | — | 允许 >100%，按「整数层 + 小数概率」解释 | ✅ | 见第 0.3 节 |
| 元素触发占比 | — | 该元素伤害 ÷ 所有类型伤害之和 | ✅ | 见第 0.3 节 |

### 6.2 DoT 完整结算链（2026-11-05 确认）

```
① 触发时的"基础命中伤"
   = 命中伤害中【剔除元素/物理 Mod 加量】后的值
     · 保留：基伤%、多重%
     · 剔除：所有元素 Mod 与物理 Mod 的加量
     · 计入：全部伤害类型（物理 + 元素）

② 基础触发值 = ① × 该元素系数
   · 该值【享受暴击】——即 ① 里已含暴击期望，DoT 自身不再产生暴击

③ 每跳伤害 = ② × (1 + Σ该类型元素Mod%) × (1 + Σ派系伤害%)
   · 元素类型加成：以触发元素自身类型为准
   · 派系加成：DoT 在"基础值"（步骤①）处已享受一次，
     此处再享受一次 → 这就是 DoT「派系加成两次」的真实机制（非平方）

④ 每秒 DoT = Σ 各跳（层数 × 每跳）                                  ← 输出口径
```

> **与第 0.3 节的关系**：第 0.3 节负责「触发概率 / 期望层数」，本节负责「触发之后 DoT 怎么算钱」。
> 连起来：第 0.3 节算出「每秒叠几层」→ 本节用这些层数 × 每跳伤害 = 每秒 DoT 输出。

### 6.3 叠层与刷新

| 元素 | 叠层规则 | 刷新行为 |
|---|---|---|
| 火焰 | **无上限**，合并为每秒一次的持续伤害 | 叠加时**刷新持续时间**，并为触发器**增加新加入的基础值** |
| 毒素 | **无上限**，每层**独立计时** | 各自倒计时，互不覆盖 |
| 电击 | **无上限**，每层**独立计时** | 各自倒计时 |
| 切割（流血） | **无上限**，每层**独立计时** | 各自倒计时 |
| 毒气 | **10 层上限** | 超过 10 层时，新效果**替换最早的一层** |
| 爆炸 | 见 6.4，**非 DoT** | — |

- **火焰特例**：所有火焰合并为每秒一次的持续伤害；元素类型加成与派系加成**以第一层为准**。
  但在**单武器伤害模拟层面没有影响**（同源同值）。
- **毒气特例**：只享受**对应类型（毒气）**的元素 Mod 加成，
  **不享受组合成它的单元素（毒/火）Mod 加成**。
- **所有异常状态**都享受「**异常状态伤害 +X%**」Mod 加成（百分比增加）。

### 6.4 爆炸（Blast）：堆叠结算，非 DoT

```
单层：1.5 秒后造成【基础伤害 × 30%】
满 10 层：立即结算（无需等待），对目标造成 10 次 30% 基础伤害
范围爆炸：每层 300% 基础伤害（= 单体 10 倍），单次伤害，5 米范围
死亡时：若已叠层，同样按上述规则结算
```

- 不满 10 层的爆炸异常，才需要等待 1.5 秒触发。
- **范围伤害只在「满 10 层立即结算」时产生**：
  - 满 10 层结算 → 单体 10×30% + **范围 300%/层（10 倍）**
  - 满时长结算（未满 10 层）→ **只有单体伤害，无范围伤害**
- **模拟层面前提**：先用第 0.3 节的「期望每秒叠加层数」判断
  能否在 1.5 秒内叠满 10 层；能叠满则按「立即结算」计（含范围），否则按「满时长结算」计（无范围）。
- 曲线展示见第 0.2 节：爆炸按**每秒平均伤害**给出。

## 7. 目标结算

> 目标模型字段：`headshotMultiplier`（爆头倍率，默认 3.0×，按敌人配置，见第 3.2 节）。
> **结算顺序：先护盾 → 破盾后再按护甲/生命结算。**

### 7.1 结算顺序

```
① 目标有护盾 → 只吃「对护盾」加成，先扣护盾
② 护盾为 0 → 按护甲（有则扣减）→ 最后扣生命
③ 病毒加成只在「生命值阶段」生效，护盾阶段不生效
```

### 7.2 护盾与超盾

- **修正草案**：磁力**不穿盾**。真正能穿盾的是**毒素**（绕过护盾直接作用于生命）。
- **磁力异常**（对护盾增益）：
  ```
  首层：对护盾与超盾伤害 +100%，并使护盾再生无效，持续 6 秒
  后续每层：+25%
  上限 10 层：最高 100% + 9×25% = 325%
  ```
- 磁力加成作为**目标结算阶段的独立乘区**，按目标当前护盾/超盾阶段乘上。

### 7.3 病毒异常（对生命）

```
首层：对生命值伤害 +100%，持续 6 秒
后续每层：+25%
上限 10 层：最高 325%
仅在生命值阶段生效（护盾存在时不生效）
```
同样作为**目标结算阶段的独立乘区**。

### 7.4 护甲与削甲（完整数值）

**护甲减伤公式**
```
伤害减免 = 0.9 × (护甲 / 2700)^0.5
```

**腐蚀异常（削甲，数值型）**
```
每层：降低目标 26% 护甲，持续 8 秒
叠加：每层 +6% → 26% + 6%×(n-1)
上限：80%（`26 + 6×9 = 80`，即 10 层达到）
计时：每层持续时间独立计算
```

**火焰灼烧（削甲，时序型）**
```
从首次触发起，每 0.5 秒削一次，依次为：
  15% → 30% → 40% → 50%     （共 2 秒达到 50% 峰值）
多次触发灼烧不会加快该过程
效果结束后，每 1.5 秒恢复一次：
  50% → 40% → 30% → 15% → 0%   （6 秒后完全恢复）

触发持续时间 Mod 会等比例拉长间隔：
  +100% 持续时间 → 削减间隔 0.5s → 1.0s，恢复间隔同步拉长
  裂罅的触发时间减益词条则缩短该间隔
```

**削甲合并**
- 腐蚀与火焰的削甲**叠乘共存**：`有效护甲 = 护甲 × (1-腐蚀%) × (1-火焰%)`。
- 与其他类型的护甲削减效果之间同样为**叠乘**。

### 7.5 超宏防护（Overguard）

```
除虚空伤害外：无任何伤害抗性与弱点
不受：目标自身护甲减免、护盾、生命类型影响
仍受：其他伤害抗性/易伤手段（如守护者卓越者光环）、部位倍率
```

| 对超宏防护 | 是否生效 |
|---|---|
| 磁力异常（对护盾 +100%~325%） | **生效** |
| 病毒异常（对生命 +100%~325%） | **不生效** |
| 毒素穿盾 | **不穿透** |
| 护甲减免 / 护盾 / 生命类型 | **不适用** |

### 7.6 结算顺序汇总

```
① 超宏防护存在时 → 单独结算（磁力生效、病毒不生效、毒素不穿透、无护甲减免）
② 有护盾 → 只吃对护盾加成（磁力），先扣护盾
③ 护盾为 0 → 按有效护甲（含腐蚀/火焰削甲，叠乘）扣减 → 最后扣生命（病毒生效）
```

### 7.7 展示口径：削甲的时态处理

火焰削甲是**时序型**的（2 秒爬到峰值、6 秒恢复完），与瞬时静态乘区本质不同：
同一配置在「第一发」与「持续射击若干秒后」结果不同。

```
主展示值   = 稳态（削甲已达峰值：腐蚀满层 + 火焰 50%）
对比展示   = 首发 / 无削甲状态
```

- 主展示值用**稳态护甲**计算，代表持续输出的典型表现。
- 同时提供「首发/无削甲」作为对比，避免误读。

## 8. 灵化 / 赋能 / 自定义外部加成

### 8.1 三种「外部加成」的共同模型

三者都**不单独拆新乘区**，而是按效果**落到已经定义好的某个乘区**里。
每一项加成必须声明两件事：

```
① 落点：作用在哪个乘区（任选，见第 2~7 节已定义的全部乘区）
② 类型：三种之一 ↓
```

| 加成类型 | 含义 | 在骨架中的位置 |
|---|---|---|
| **Mod 类（百分比）** | 百分比增加 | `( 面板值 × (1 + ΣMod%) + 固定值 ) × 额外乘区` 的 `ΣMod%` 内 |
| **绝对增加** | 计算完 Mod 后，加一个固定值 | 同一骨架里的 `+ 固定值` 项 |
| **乘算（额外乘算乘区）** | 独立额外乘区 | 同一骨架里的 `× 额外乘区` |

> 这正是第 2.0 节通用骨架的三个位置。第 8 节**没有引入新结构**，
> 只是把「用户自定义的加成」按类型塞进骨架的对应位置。

### 8.2 每个乘区都可设置

- 全文所有已定义乘区（基伤、多重、暴率、暴伤、触发、元素、物理、射速、派系、DoT 相关…）
  **都可作为自定义加成的落点**，任意组合上述三种类型。
- 仍需声明**作用域**：作用于**单发命中**还是 **DoT**（二者计算链不同，见第 6.2 节）。

### 8.3 灵化加成

- **灵化加成的选择入口**：位于**武器面板下方**的**选择框**（在 Mod 拖放区**左侧**）。
- 用户在框中选择使用哪个灵化加成；选择后按其效果落到对应乘区。
- 具体加成数值由人工维护层提供（见 `data-todo` 第 2 节）。

### 8.4 赋能加成

- 按赋能效果落到对应乘区，走 8.1 的同一模型。
- 赋能数值按等级提供，支持逐级选择（等级 1~最大）。

| 属性 | 乘区 | 与其他属性的关系 | 状态 | 备注 |
|---|---|---|---|---|
| 灵化加成 | 落到对应乘区 | 不单独拆乘区；面板下方选择框、Mod 区左侧 | ✅ | 数值走人工维护层 |
| 赋能加成 | 落到对应乘区 | 不单独拆乘区；按等级取值 | ✅ | |
| 自定义外部加成 | **任意乘区** | 三种类型：Mod类（%）、绝对增加、乘算（额外乘区） | ✅ | 须声明作用于单发还是 DoT |
