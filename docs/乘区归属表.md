# 乘区归属表（草案 · 待逐条确认）

> 状态：**草案**。每一行都需要与需求方确认后才能固化为公式。
> 确认方式：在「状态」列标记 ✅（同意）/ ❓（有疑问）/ ❌（不同意），并在备注里写明理由。

## 0. 结算链总览

```
面板基础值
  → L1 加法乘区（基伤、多重、暴率、暴伤、触发、元素、射速…）
  → L2 元素组合（物理 + 元素 → 复合元素，按 Mod 槽位顺序合并）
  → L3 暴击结算（期望倍率 / 超暴击层数 / 弱点倍率）
  → L4 触发状态机（每弹头独立判定 → 各元素 DoT / 叠层 / 连锁）
  → L5 目标结算（护甲、护盾、派系、削甲）
```
