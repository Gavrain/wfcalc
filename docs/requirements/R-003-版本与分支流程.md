# 需求 R-003：版本与分支流程

- **状态**：已完成
- **提出**：需求方 2026-11-16
- **版本**：v1.0.0

## 要什么

> "发布一个 1.0 版本，之后的 bugfix 和 feature 都单独开分支开发，单独作为 commit 提交。"

## 结果

- v1.0.0 在 2026-11-16 打标签并发布；
- 分支与提交规范写进 [`../../CONTRIBUTING.md`](../../CONTRIBUTING.md)；
- 每个版本配一份 `../releases/vX.Y.Z.md`。

## 怎么定的

需求方选择"丙"方案：1.0 先发布，重写内核作为 2.0 在独立分支上做，不在 1.0 里冒险。
