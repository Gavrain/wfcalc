# 需求 R-001：核心口径修正

- **状态**：已完成
- **提出**：需求方 2026-11-16
- **版本**：v1.0.0

## 要什么

把之前算错的口径改正，**不加新口径**。

## 为什么

需求方原话："今晚做的就是修正，是因为之前有的口径计算不正确。"

## 改了什么

| 项 | 原口径（错） | 现口径（对） |
|---|---|---|
| 乘区下限 | 负词条能把乘区压成负数 | 算完括号后最终值最低 0 |
| 弱点暴击率 | 加在暴击率括号**外面**（+350% 被当成 +3.5） | 与普通暴率在**同一个 Σ 括号**，且只在开爆头时计入 |
| 重击 ×2 | 只在结算里加倍，面板显示不加倍 | 面板 / 拆解 / 结算共用一个折算 |
| DoT 基础值 | 同一值有两个名字、各算一遍 | 收敛成一个，每跳与爆炸共用 |
| 多重与触发率 | 射线在触发率里乘多重、叠层不乘 | 触发率不乘多重，叠层那一侧乘（数学恒等，位置换了） |
| 弹药效率 | 上限 0.95 | 上限 0.75（等效弹匣最多 4 倍） |
| 稳态秒伤 | 层数永不到期，高射速虚高 | 逐秒层数池（会到期清除），并计入爆炸主目标 |
| 逐段面板 | 变体 override 在面板侧被忽略 | 面板取值：变体 → 模式 → 武器级 |

## 证据 / 验证

typecheck 通过；636 项测试全过。

## 怎么定的

需求方确认"这些是修正，不是新功能"；"异常加权单层秒伤"保留不动，"真正的异常每秒伤害"属于新口径，留到 1.0 之后单独开分支。
