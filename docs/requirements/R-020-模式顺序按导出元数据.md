# 需求 R-020：模式顺序按导出元数据，普通射击排最前

- **状态**：已完成
- **提出**：需求方 2026-11-18
- **版本**：v1.4.0

## 要什么

> 「玄骸武器普通射击模式应该在最前面」
> 「这应该符合导出元数据的顺序」

即：一个模式是「普通射击」还是「蓄力射击 / 灵化形态」，不能只看模式名里带不带 `Charge`；
排序要跟着导出元数据里攻击的先后走。

## 问题

1. **速射被当成蓄力**：弓的 `Uncharged Shot`、`Quick Shot`、兰卡的 `Partially Charged Shot`
   名字里都不带「蓄力」，掉进了普通模式；同一把弓的 `Charged Shot` 反而是蓄力 → 满蓄力排第一。
2. **导出顺序被改成「蓄力优先」**：主攻击锚点（`Charged Shot` / `Quick Shot` / `Perfect Shot`…）
   被一刀切成蓄力，随后蓄力整体前移（雷米利亚、布拉玛都是这样被翻过来的）。
3. **灵化位置不稳**：导出里 `Incarnon Form` 夹在未蓄力与满蓄力之间，排序后又可能排到中间。

## 证据

WFCD 的 `attacks[]` 本身就是按「速射 → 满蓄力」导出的，例：

```
Cernos:          Uncharged Shot → Charged Shot
Daikyu Prime:    Quick Shot     → Charged Shot
Rakta Cernos:    Uncharged Shot → Charged Shot
Kuva Bramma:     Charged Shot   → Radial Attack → Cluster Bomb Contact → …
Lanka:           Partially Charged Shot → Charged Shot
```

## 怎么定的

- **速射 = 普通射击**：带 `Uncharged` / `Quick` / `Partially Charged` / `Normal Shot` 的都算普通，哪怕官方给了蓄力时间。
- **满蓄力 = 蓄力射击**：带 `charge` 词且不是上述否定说法的算蓄力；近战 / 投掷 / 回旋刃的「蓄力攻击」不算（它们不是射击模式）。
- **顺序按导出元数据**，只有两条硬规则：
  - 灵化永远最后；
  - 普通射击排蓄力之前，唯一例外是满蓄力更有代表性的弓炮（西诺斯、巴黎、恐惧、太始弓、米特尔、科瓦斯…）。
- **只改类别与顺序，不改任何数值**：段的伤害 / 暴击 / 触发 / 射速一律不动（逐把对比：652 把武器里段内容 0 变化）。
- 模式 id 仍是存档的键：第一个普通模式叫 `primary`，其余沿用建组时的 `modeN`。
- 验证页补上「玄骸加成」一行（该页原来没有元素控件，玄骸加成只能按默认火算却一个数都不显示）。

## 影响

11 把多模式武器的顺序 / 类别发生变化，例如：

| 武器 | 之前 | 之后 |
|---|---|---|
| 西诺斯（Cernos） | 满蓄力 / 普攻 | 普攻 / 满蓄力 |
| 雷米利亚（Rakta Cernos） | 满蓄力 / 普攻 | 普攻 / 满蓄力 |
| 赤毒·布拉玛 | 集束炸弹 / 满蓄力 | 满蓄力 / 集束炸弹 |
| 大久和弓 Prime | 满蓄力 / 速射 | 速射 / 满蓄力 |
| 兰卡 | 部分蓄力 / 满蓄力 | 部分蓄力 / 满蓄力（满蓄力 id 改为 `mode2`） |
