## 写新需求时

1. 接着最大编号 +1，文件名用短标题；
2. 内容只写：**要什么 / 为什么 / 证据 / 谁提的 / 怎么定的 / 落到哪个版本**；
3. 讨论过程中的否定方案不写进正式记录，只在"怎么定的"里一句话说明取舍；
4. 实现完成后把状态改成「已完成」，并在 `releases/` 对应版本里引用编号。
