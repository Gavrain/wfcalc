# 需求 R-004：文件组织形式

- **状态**：已完成
- **提出**：需求方 2026-11-17
- **版本**：v1.0.0

## 要什么

> "代码要跟 doc 类分开来吧。需求讨论跟发布记录还有开发规范也应该分开来吧。
>  虽然是一人项目，但是考虑到多会话并行开发。要按照标准的协作软件开发项目来做。"

## 结果

```
wfcalc/
├── README.md          项目总览
├── CONTRIBUTING.md    开发规范（分支 / 提交 / 评审 / 注释）
├── CLAUDE.md          协作红线摘要 + 指向 CONTRIBUTING
├── docs/
│   ├── specs/         口径与设计（结论）
│   ├── requirements/  需求讨论（来龙去脉）
│   └── releases/      发布记录（版本存档）
├── packages/          代码
└── research/          研究记录
```

同时删掉：决策台账 `docs/decisions/`、`乘区归属表.md`、`变量依赖图.md`、`data-todo/`（当年数据清洗没做好的遗留），以及内容已并入其他文件的 6 份文档。

## 怎么定的

需求方逐条确认：决策台账没必要留；口述记录型的文档会误导，删除；`data-todo` 是遗留，删除。
