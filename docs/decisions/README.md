## 写新决策时

1. 挑一个**对的文件**放（上面第一张表），不要新开文件；
2. 编号接着最大的加 1（当前最大 **D-206**）；
3. 只在状态表里加一行，正文写进 `../核心事实.md` 的对应小节；
4. 如果新决策推翻旧的，把旧行标注「被 D-新号 取代」。
