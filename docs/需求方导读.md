## 一、这是什么

一个 Warframe 武器伤害计算器。你配好 Mod、赋能、玄骸元素，它告诉你伤害是多少，
而且能**拆开看每个加成项各自贡献了多少**——这是它和普通计算器的区别：每个数字都能复算、可溯源。

## 二、怎么打开看

```bash
node packages/demo/src/server.mjs
# 浏览器打开 http://127.0.0.1:5178
```

打开后你能：选武器、拖 Mod、装赋能、切玄骸元素、看六种输出口径（单弹头/单次/每秒/持续/DoT…），
点任意 Mod 或赋能看它到底加了哪些乘区。

## 三、现在做到哪了（通俗版）

- ✅ 核心计算：暴击、爆头、元素合成、玄骸、触发率、DoT、装填空窗、六秒异常总伤，全都能算。

  这些在界面里都有标记，不会骗你算错。
