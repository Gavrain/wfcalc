### A. 爆炸范围与伤害衰减

官方 `ExportWeapons.json` 只给 `explosiveAttack` 的伤害，不给半径、也不给距离衰减公式。

| 字段 | 含义 |
|---|---|
| `noSelfDamage` | 是否有自体伤害豁免 |
| `radius` | 爆心半径（米） |
| `falloffStart` / `falloffEnd` | 衰减起止距离（米） |
| `minMultiplier` | 边缘处伤害倍率 |
| `damageFactorAtCenter` | 爆心是否额外加成 |
