# 核心事实（唯一权威）

> 这是"现在按什么算"的唯一权威文件。口径有矛盾时以本文件为准。
> 代码注释里出现的"依据：核心事实 §X"，就是这里的小节号。
> 本文件只收**当前的结论**；过程、被推翻的旧写法、开发记录一律不收。

## 0. 边界

- 本项目计算**武器自身的输出能力**：给定武器 + 配装 + 选项，它自己能打出多少伤害。
- **不做**：敌人类型克制（Grineer 冲击 ×1.5 之类）、护甲 / 削甲 / 护盾 / 超宏、目标部位倍率、目标结算（只算到命中伤害层）。
- **做**：派系歧视 Mod（它是配装的一部分，不是敌人属性）。

## 1. 单位与取值

- 面板暴率 / 触发率是 **0~1 小数**；贡献值一律**百分比口径**（165 = +165%）；绝对值用属性自身单位（暴率 5 = +5 个百分点）。
- 面板多重取 `mode.multishot`，**不是常量 1**（58 把武器面板多重 > 1）。
- 通用乘区骨架：`(面板值 × (1 + Σ百分比) + Σ绝对值) × Π乘算`，**最终值最低 0**，括号照常算给拆解看。
- 只算期望平均值，不做随机模拟、不取整；浮点只在展示层四舍五入。

## 2. 结算顺序

```
① 玄骸加成并入面板（在基伤之前，吃基伤加成）
② 基伤（含镀层 / 冷颤两路）；多重是独立乘区、与基伤相乘
③ 物理 %        （基数 = 该物理类型自身在新面板里的值）
④ 元素 %        （基数 = 新面板总伤，不含物理 % 的加量）
⑤ 元素合成      （同类型先合并 → 按槽位号两两配对；自带元素在 Mod 槽位之后，从 9 号起）
⑥ 独立乘区      （处决 / 震地 / 身体伤害）
⑦ 暴击 + 爆头
⑧ 派系（命中一次、DoT 每跳再一次）
⑨ 触发与叠层 → DoT 每跳 → 爆炸
⑩ 输出口径
```

## 3. 基伤与镀层

- 基伤两路：`面板基伤 × (1 + Σ基伤% + 镀层% + 冷颤%) + 被动基伤 × (1 + Σ基伤%)`。
- 镀层类加量 = `每层值% × 异常种类数 a × 叠层数 y`；**只看种类数，不按层数**。
- 镀层与冷颤**不吃**被动基伤那一路，也**不吃**范围伤害（`explosiveAttack`）。
- 冷颤固定按满层 10 层；只对直接命中生效（AoE 段不吃）。
- **叠加层数 y、目标异常种类数 a 是上下文（由界面传入），不是由数据导出的**。

## 4. 多重与触发

- 多重独立乘区，与基伤相乘。
- 触发率 = `面板触发率 × (1 + Σ触发%)`，**不看多重**（游戏内显示口径）。
- 单发某类型的期望层数 = `触发率 × 该类型占比 × 多重`；射线与实弹**同一条公式**。
- 射线的多重**并进单弹头伤害**（一次射击算一跳）；实弹的单弹头不含多重。

## 5. 暴击与爆头

- 平均伤害倍率 = `1 + 暴率 × (暴伤 − 1)`；上下限用 `1 + k × (暴伤 − 1)`，k = floor(暴率)。
- 爆头是**开关**（不勾选时整项不存在）。
- **爆头倍率与弱点伤害在同一个乘区里算**：
  ```
  爆头倍率 = 敌人配置倍率（默认 3）× (1 + Σ爆头伤害% + Σ弱点伤害%)
  ```
  它们在词条层面是**两个不同的键**（`headshotDamage` / `weakpointDamage`），只在算爆头倍率时才并到一起。
- **弱点暴击率**（敏锐主武 / 敏锐手枪）与普通暴率是**同一个 Σ 括号**；引擎在算暴击率时**先看爆头开关**，开启才把弱点暴击率并进去，关闭时整条不生效。
- **爆头且暴击**额外 ×2，只作用于暴击那一下。
- 暴击率最低 0；暴率可 > 100%。
- **重击 ×2**：带重击标记的暴率贡献在重击系攻击上再算一份（按数据给出的标记判断，不按 Mod 名字）。
- 刃影：一级暴击概率决定增益，倍率 `1 + w·P1(暴率)`，只乘命中平均与叠层，**不乘 DoT 每跳基础值**。

## 6. 元素与玄骸

- 元素 % 只是"按新面板总伤算出该元素自己的加量"，不是总伤放大器。
- 玄骸加成 = 面板总伤 × 比例（25%~60%），**并入面板之后再吃基伤**；玄骸类型 ∈ {冰、火、毒、电、磁力、辐射、冲击}。
- 槽位：Mod 槽 0~7，试算槽 8，自带 / 玄骸元素从 9 号起；自带元素内部优先级 火 > 冰 > 电 > 毒。
- 只有冰 / 火 / 毒 / 电参与融合；复合元素（自带或玄骸）不占融合槽位、不参与配对。
- 毒气只吃"毒气 %"，不吃火 % / 毒 %。

## 7. 触发与 DoT

- **DoT 基础值（唯一一份）** = 命中分布**剔除元素/物理 % 加量**之后 × 处决/震地/身体 × 暴击期望 × 派系 × 多重（射线）。
- 每跳 = 基础值 × 该类型系数（火/毒/电/毒气 0.5，切割 0.35）× (1 + 该类型元素%) × (1 + 异常状态伤害%) × (1 + 派系%)。
- 派系在 DoT 上**乘两次**（基础值一次、每跳一次）是已确认口径。
- 某类型会不会掉血，只看**合成结束后的命中分布里有没有它**。
- DoT 每跳**不吃**暴击（暴击已含在基础值）。
- 叠层：火/毒/电/切割无上限，毒气 10 层封顶；电击 / 毒气在 0 秒立即跳一拍。
- **异常加权单层秒伤**：分母只算"有 DoT 的五种类型"的触发占比；**N 秒异常总伤**的层数则按所有伤害类型的触发占比取。两个口径各自成立，都保留。

## 8. 爆炸

- 主目标：每层恒定 30%，叠几层算几层，**无上限、无满层跃升**，1.5 秒延迟只决定何时结算。
- 周围敌人：1.5 秒内叠满 10 层（或目标死亡）才触发，每层 30% → 300%，5 米；**单列展示，不进任何总伤**。
- 爆炸不吃元素 %。

## 9. 时间（装填与窗口）

- 一个循环 = 弹匣 ÷ 射速 + 装填时间；装填期间**不叠新层，已有层照常跳**。
- 窗口 N 秒（1~6，默认 6）；窗口内直击按**真实开火时长**积分，不按"续航秒伤 × N"。
- 稳态秒伤 = 续航秒伤 + 一个循环内异常每秒（层数会到期清除）。
- 弹匣 0 的武器：续航秒伤 = 连发秒伤。

## 10. 输出口径清单

单弹头 / 单次射击 / 连发秒伤 / 续航秒伤 / 异常加权单层秒伤 / N 秒异常总伤 / N 秒总伤 / 稳态秒伤。

## 11. 数据层给内核的结构化事实（内核只读这些，不读名字）

- 每个伤害段：类型（impact / attack / explosiveAttack）、伤害分布、自身触发率、是否 AoE、是否射线（段级或变体级）、所属变体的扳机。
- 每个模式：扳机、面板多重、变体列表；`_heavy` / `_slam` 标记。
- 每条贡献：属性键、形态（pct / flat / mul）、值、来源、槽位、`active`、`locksFireRate`、`locksMultishot`、`heavyX2`。
- 武器级被动：`baseDamageFlat`（按每段自己的面板分布平摊）。
- 赋能：数据层给出每层值与层数上限；连击倍率、爆发层数由界面传入。
- `embedDeathAttack`（碎尸比例）、占位段（腐蚀 3 + 触发 0.3）**不是伤害**，已被清洗剔除。

## 12. 内核与数据的分工（v2 起）

- **场景由数据层决定**：不同射击模式是不同场景，UI 只负责多场景渲染。
- **条件判断写在内核**：爆头开关、重击、震地这类"某条件下某键才生效"，直接写在对应乘区里，不引入规则表、不写成数据里的条件语句。
- **只有"把某乘区的结果拿去生成另一乘区的加成"才需要单独的派生步骤**（目前没有真实数据用到）。
- 自然语言写的规则存在歧义，不作为实现依据；实现只认数据里的结构化字段。

## 13. 模型标记（数据字段，供溯源）

| 标记 | 含义 |
|---|---|
| `_manual: 'panel-reused'` | 面板复用基础面板的占位值（灵化形态未收录） |
| `_manual: 'entered'` | 人工录入的真实值 |
| `_manual: 'bible'` | 导出值与游戏不符，按游戏内白板改写 |
| `_manual: 'export-missing'` | 导出不可用，数值来自人工层 |
| 武器 `panel-empty` | 面板尚未收录，不能参与计算 |
