# 文档索引

> 文档按**用途**分目录：口径与设计给写代码的人看；需求给人追溯用；发布记录按版本存档。

| 你想找 | 去哪 |
|---|---|
| 现在按什么算（**唯一权威**） | [`specs/核心事实.md`](specs/核心事实.md) |
| 计算内核的架构设计 | [`specs/架构设计/`](specs/架构设计/) |
| 某条需求怎么来的、做到哪了 | [`requirements/`](requirements/README.md) |
| 每个版本改了什么 | [`releases/`](releases/README.md) |
| 数据源与抓取口径 | `../research/` |

## 规矩

- **`specs/` 是结论**：只写"现在按什么算"，不写过程、不写历史。
- **`requirements/` 是来龙去脉**：谁提的、为什么这么做、证据是什么、对应哪个版本。
- **`releases/` 是版本存档**：每个 `vX.Y.Z` 标签一份，内容 = 改了什么 + 验证结果 + 已知问题。
- 口径有矛盾时，**以 `specs/核心事实.md` 为准**，并回头修正另外两处。
