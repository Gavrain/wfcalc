# 衰减：两种模型，只做面板展示（D-070）

> 需求方 2026-11-06 口径：
> 「霰弹衰减有两段，第一段内全伤害，到第二段线性下降，第二段之外又保持不变。
> 爆炸武器则是只有一个范围，从爆炸中心到范围线性衰减。而且这东西不影响伤害计算，
> 只是作为面板展示。」

## 1. 两种模型

```
甲 · 爆炸（explosion）          只有一个半径
   伤害
   100% ┤●
        │ ╲
        │  ╲
   边缘 ┤   ●────────  半径之外：不结算
        └───┴───────► 距离
            radius

乙 · 霰弹（shotgun）            两段
   伤害
   100% ┤●────●
        │      ╲
        │       ╲
   边缘 ┤        ●────  end 之外：保持边缘值不变
        └───┴──┴─────► 距离
         start end
```

| 模型 | 字段 | 含义 |
|---|---|---|
| explosion | `radius` | 外缘半径；中心 → 半径线性衰减 |
| shotgun | `falloffStart` | 全伤害区边界 |
| shotgun | `falloffEnd` | 衰减区结束；此后保持边缘值 |
| 两者 | `edgeMultiplier` | 边缘倍数 = `1 − WFCD.reduction`（需求方批注确认，0.3 → 剩 0.7） |

## 2. 怎么判一条 WFCD 记录属于哪一种

WFCD 用同一套 `{start, end, reduction}` 描述两种模型，**数据本身不区分**。生成器的判据：

| 条件 | 判定 | 说明 |
|---|---|---|
| 本地段是 `embedDeathAttack` | explosion，`radius = end` | 炮弹嵌入后爆开，只能是爆炸 |
| `start ≥ end` 或 `start = 0` | explosion，`radius = end` | 按霰弹模型 start 应 > 0；`start = 0` 更像"没填" |
| 其它（`0 < start < end`） | shotgun，`start/end` 原样 | 两段衰减的都落在这里 |

**判据不可靠的会进 `wfcd-confirm.csv` 的「衰减模型」行**，你只需要在「填写」列写
`explosion` 或 `shotgun`。

## 4. 和伤害计算的关系

**没有关系。** 内核 `resolveSegment()` 不读这些字段，接入方式是配装页的面板展示。
因此不需要改结算链，也不构成"口径变更"（D-070 已记录）。
