# 太始弓（Nataruk）数据获取尝试记录

> 结论：**所有自动抓取渠道均不可用，需人工维护。**
> 验证日期：2026-11-05

## 为什么需要单独处理

太始弓（Nataruk）**不在**官方导出 `ExportWeapons.json` 里：

- 按 id / 图标名含 `nataruk`：0 条
- 按 `stateName` 含 `Perfect`：0 条
- Zariman 路径下只有 6 把武器，含 2 把长枪（`ZarimanSemiAutoRifle` / `ZarimanPumpShotgun`），没有弓
- 懒人表（`WEAPON_DB`）里有 `nataruk_perfect`，但**中文名为空**（`"zh": ""`）

## 抓取尝试记录

| 渠道 | 结果 | 说明 |
|---|---|---|
| `wiki.warframe.com/w/Nataruk` | **HTTP 403** | Weird Gloop 反爬（"Please wait" 浏览器校验页） |
| `wiki.warframe.com/api.php`（多个 action） | **HTTP 403** | 同上，API 同样被拦 |
| `warframe.fandom.com` | **ECONNRESET** | 连接被重置 |
| `warframe.huijiwiki.com` | **HTTP 403** | 同样的反爬页 |
| `api.warframestat.us` | **HTTP 403** | Cloudflare 拦截 |
| `WFCD/warframe-items` raw 路径 | **404** | 仓库结构已变更，旧路径失效 |
| `WFCD/warframe-items` GitHub API | **403** | 未认证请求被限流 |
| `codeload.github.com` tarball | **502** | 服务端错误 |

结论：**当前环境无法从任一渠道自动取得太始弓数据。**

## 需要人工维护的字段

请按下面的结构填写，放进 `data/manual/secret-weapons.ts`（或直接给 Excel，我来转换）：

| 字段 | 说明 | 示例 |
|---|---|---|
| `name.en` / `name.zh` | 名称 | Nataruk / 太始弓 |
| `critChance` | 暴击几率 | |
| `critMultiplier` | 暴击倍率 | |
| `statusChance` | 触发几率 | |
| `fireRate` | 射速 | |
| `modes[]` | 攻击模式列表 | |

每个 `mode` 需要：

| 字段 | 说明 |
|---|---|
| `id` | 模式标识，如 `uncharged` / `charged` / `perfect` |
| `trigger` | `charge` |
| `segments[].kind` | `attack` 等 |
| `segments[].damage` | 伤害分布，如 `{ impact: 10, puncture: 20, slash: 30 }` |
| `segments[].procChance` | 触发几率 |

**已知的形态区分**（据需求方说明）：

- 太始弓是**三面板**武器：未蓄力 / 蓄力 / 完全蓄力（Perfect Shot）
- 完全蓄力（Perfect Shot）伤害显著更高
- 每个形态的暴击、触发数值可能不同，需逐个填写
